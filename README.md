Proyek: proyek_sesi4

Deskripsi:
Aplikasi Flutter sederhana menampilkan layout film dengan:
- Carousel "Now Playing" (menggunakan package carousel_slider)
- Section horizontal: Trending, Popular, Top Rated
- Data dummy menggunakan gambar lokal (assets/images)

File penting:
- lib/main.dart
- pubspec.yaml
- assets/images/poster1.png ... poster6.png

Panduan singkat penggunaan:
1. Ekstrak folder proyek_sesi4.zip
2. Buka terminal di folder proyek_sesi4
3. Jalankan:
   flutter pub get
   flutter create .
   flutter run

Catatan:
- Perintah 'flutter create .' akan men-generate folder android/ ios/ dan file konfigurasi yang diperlukan.
- Pastikan Flutter SDK sudah terpasang dan environment PATH sudah diatur.
